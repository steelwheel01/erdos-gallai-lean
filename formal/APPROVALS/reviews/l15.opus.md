## 1. Manuscript text

`s3.tex` l. 100–108, Lemma `s3:lemL15p` (the Spec docstring quotes it verbatim):

> Let $X$ be an $N$-vertex $(\varepsilon',s)$-expander with $0<\varepsilon'\le1$, put $L:=\log N$,
> and let $k\ge1$ be an integer with $s\ge 40kL$. Give every edge of $X$ a colour from $[k]$,
> independently and uniformly at random, and for $i\in[k]$ let $X_i$ be the graph with vertex set
> $V(X)$ whose edges are the edges of colour $i$. Then for each $i\in[k]$, $X_i$ is an
> $(\varepsilon',s/(2k))$-expander with probability at least $1-2N^{-5}$. Hence all $k$ classes
> are $(\varepsilon',s/(2k))$-expanders with probability at least $1-2kN^{-5}$.

Conventions used:
* `s3.tex` l. 27–33: "Logarithms are to base $2$ … The letter $\varepsilon'$ always denotes a
  generic expansion parameter in $(0,1]$."
* `s1.tex` l. 321–328, s1:convGraphs:
  * (a) "$|H|\defeq|V(H)|$ … $[k]\defeq\{1,\dots,k\}$";
  * (b) "$\log=\log_2$ throughout".
* `s1.tex` l. 497–509, s1:citDef11: "An $n$-vertex graph $G$ is an
  $(\varepsilon,s)$-expander if for every $U\subseteq V(G)$ and every $F\subseteq E(G)$ with
  $1\le|U|\le2n/3$ and $|F|\le s|U|$ we have $|\Nbr_{G-F}(U)|\ge\varepsilon|U|/\log^2n$."
* Proof (l. 110–171). It treats $N=1$ separately ("no set $U$ satisfies $1\le|U|\le 2N/3$"), and
  it notes: "Neither $\varepsilon'$ nor the logarithm $L$ changes, because $X_i$ has the same
  vertex set as $X$."

## 2. The statement as elaborated (`#print`, `L15Test.lean`)

### Back-translation (plain mathematics)

Let:
* $V$ be any type with decidable equality;
* $X$ be a finite simple graph with vertex set $V(X)\subseteq V$, and $N:=|V(X)|$;
* $\varepsilon',s\in\mathbb R$, and $k$ a positive integer.

Assume:
* $0<\varepsilon'\le1$;
* $40\,k\log_2 N\le s$, where $\log_2 0:=0$;
* $X$ is an $(\varepsilon',s)$-expander in the sense of Def. 11 ($n=N$, $\log=\log_2$).

Draw $c:E(X)\to\{0,\dots,k-1\}$ uniformly at random; each colouring has probability
$k^{-|E(X)|}$, so the colours of the edges are independent and each is uniform. For each colour
$i$, let $X_i$ be the graph with vertex set $V(X)$ and edge set $\{e\in E(X): c(e)=i\}$. Then:
1. for every $i$, $\Pr[X_i$ is an $(\varepsilon',s/(2k))$-expander$]\ \ge\ 1-2N^{-5}$;
2. $\Pr[\forall i,\ X_i$ is an $(\varepsilon',s/(2k))$-expander$]\ \ge\ 1-2kN^{-5}$.

Here $N^{-5}$ is read as $0$ when $N=0$.

## 4. Edge cases and Lean conventions

* **`N = 0`.**
  * Lean gives `(0:ℝ)^(-5:ℤ) = 0`, so the bounds become `1 ≤ prob`.
  * `logb 2 0 = 0`, so the hypothesis reads `0 ≤ s`.
  * Every graph without vertices is an expander, because no `U` has `1 ≤ |U| ≤ 0`. The
    colouring space has one point. So the probabilities are `1`, and the statement is true.
  * This reading is stronger than the manuscript, where $N^{-5}$ is undefined at $N=0$. That is
    harmless, since it is proved (N3).
* **`N = 1`.** `L = 0` and the hypothesis reads `0 ≤ s`. The bounds are `-1 ≤ prob` and
  `1 - 2k ≤ prob`, which are trivial. The manuscript is the same: "there is nothing to prove".
* **`N ≥ 2`.** `L ≥ 1`, so `s ≥ 40k > 0` and the bounds are non-trivial.
* **`s` negative.** This cannot happen: the hypothesis forces `s ≥ 40kL ≥ 0`.
* **Division.**
  * `s / (2 * k)`: with `k ≥ 1` the divisor is never 0.
  * Inside `IsExpander`, `ε' * |U| / L^2` needs `L = 0`, which means `N ≤ 1`. Then no admissible
    `U` exists, so the Lean convention `x/0 = 0` is never reached for the class graphs. They have
    the same `N` as `X`.
* **`Real.logb 2 G.card ^ 2`** parses as `(logb 2 N)^2`, which is $\log^2 n$.
* **ℕ subtraction.** None appears in the statement.
* **Casts.** `(X.card : ℝ)` and `(k : ℝ)` are cast before any arithmetic.
* **Typeclass assumptions.**
  * `[DecidableEq V]` is universally quantified. Any instance gives the same `Finset` membership,
    because `Decidable` is a subsingleton.
  * `Fintype ↥X.edges` is the canonical `Finset` coercion instance.
  * `DecidableEq (Fin k)` is `instDecidableEqFin`, the same instance `colourClass` picks for
    `κ = Fin k` (`rfl` check).
* **Universes.**
  * `L15pStatement.{u}` quantifies over `V : Type u`.
  * `EG.l15p : EG.Spec.L15pStatement.{u}` is universe-polymorphic. I checked it at `{0}` and at
    `{2}`.
* **Events.** `prob` takes any `Set`, via the classical indicator. The events need no
  decidability, and the set-builder events are exactly the manuscript's events.

## 6. Non-vacuity (Lean, `L15NonVac.lean`)

* `KN N` is the complete graph on `Fin N`. `KN_nbr` proves $|\Nbr_{K_N-F}(U)|\ge N-|U|-s$
  whenever $|F|\le s|U|$ and $|U|\ge1$: a vertex outside $U$ that is not a neighbour must have all
  $|U|$ of its edges to $U$ in $F$.
* `KN_isExpander`: $K_{2048}$ is a $(1,440)$-expander, with $L=11$ and $440=40\cdot1\cdot11$.
  `EG.l15p` applies to it with `k = 1`.
* `KN4096_isExpander`: $K_{4096}$ is a $(1,960)$-expander, with $L=12$ and
  $960=40\cdot2\cdot12$. `EG.l15p` applies with `k = 2`, and both conjuncts are obtained for this
  concrete instance.
* The conclusion is not trivially true. For `N ≥ 2` and `ε' > 0`, the edgeless spanning graph is
  not an expander ($U=\{v\}$, $F=\emptyset$), and this is proved in `L15Test.lean`. So for
  `k ≥ 2`, the constant colouring `c ≡ 0` lies outside the event for colour `1`. The events are
  proper, and the bound `1 − 2N^{-5} ∈ (0,1)` carries content.

## 9. Notes (none blocking)

* **N1 (task text vs file).** The task says the Spec depends on `EG.FGraph.colourClass`. It does
  not (§5). The Spec depends only on `EG.Defs.{Graph, Expander, Prob.FinDist}`. So the lock of
  this Spec does not cover `ColourClass.lean`. If a later Spec wants to name `colourClass`, the
  definition must move to `EG/Defs/**`, as the design note already says.
* **N2 (colours).** Colours are `Fin k = {0,…,k−1}` instead of $[k]$. The statement is symmetric
  in the colours, so this is a relabelling. Downstream Specs with named colour families (TPV
  $\vR_{j,c}$, $\vM$) need an explicit bijection to `Fin k`, as CONVENTIONS.md already records.
* **N3 (`N = 0`).** The Lean reading ($N^{-5}:=0$) is stronger than the manuscript, where it is
  undefined. It is proved, so this is harmless.
* **N4 (joint randomness).** The Spec is about the colouring's own sample space, and so is the
  manuscript lemma. Its downstream uses draw the colouring jointly with other randomness:
  * T16* Step 1, "uniformly and independently of $V$";
  * COL, "uniform given the split".
  These uses need a transport. `EG.l15p_of_map_eq` and `EG.l15p_prod_fst` in the proof file
  supply it. They are proved but not locked, which is fine.
* **N5 (`[NeZero k]`).** The Spec takes `k ≥ 1` as an instance binder. Callers with a
  hypothesis `0 < k` must provide `⟨_⟩` or `NeZero.of_pos`. This is a usability matter, not a
  mismatch.
* **N6 (design note).** Its remark that the per-colour bound is $1-2N^{-5}$ and the all-classes
  bound is $1-2kN^{-5}$ is correct, and the Spec states both.
