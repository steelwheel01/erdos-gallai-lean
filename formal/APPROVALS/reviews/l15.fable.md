## Manuscript text compared against

s3.tex, lines 100–110 ([s3:lemL15p], "Lemma 15⁺: random splitting without loss"):

> Let X be an N-vertex (ε′,s)-expander with 0<ε′≤1, put L:=log N, and let k≥1 be an integer
> with s≥40kL. Give every edge of X a colour from [k], independently and uniformly at random,
> and for i∈[k] let X_i be the graph with vertex set V(X) whose edges are the edges of colour i.
> Then for each i∈[k], X_i is an (ε′,s/(2k))-expander with probability at least 1−2N^{−5}. Hence
> all k classes are (ε′,s/(2k))-expanders with probability at least 1−2kN^{−5}.
> \deps{s1:citDef11, s1:citChernoff}

Its proof (lines 112–175) begins "If N=1, then no set U satisfies 1≤|U|≤2N/3, so every graph
on one vertex is an expander for all parameters, and there is nothing to prove. Assume N≥2, so
L≥1." — so the lemma is asserted for every N ≥ 1 with no size condition.

s1.tex, Convention [s1:convGraphs]: (a) "Graphs are finite and simple … For any graph H we write
|H| := |V(H)| … [k] := {1,…,k}"; (b) "log = log₂ throughout"; (c) "For U ⊆ V(H), Nbr_H(U) is the
set of vertices of V(H)∖U that have a neighbour in U … for F ⊆ E(H), H−F is obtained by deleting

s1.tex, Cited result [s1:citDef11] (Definition 11 of B–M): "An n-vertex graph G is an

### Back-translation (plain mathematics)

For every type `V` with decidable equality, every finite simple graph `X` on `V` (explicit finite
vertex set `V(X)` and finite edge set `E(X)`, loopless, ends of edges in `V(X)`), all reals
`ε′, s`, and every natural number `k ≠ 0`: if `0 < ε′`, `ε′ ≤ 1`, `40·k·log₂ N ≤ s` where
`N := |V(X)|`, and `X` is an `(ε′,s)`-expander in the sense of Definition 11 (with `n = N` and
`log = log₂`), then, writing `P` for the uniform probability measure on the finite set of maps
`c : E(X) → {0,…,k−1}` (each of the `k^{|E(X)|}` colourings has weight `k^{−|E(X)|}`, i.e. the
colours of the edges are independent and uniform), and writing `X_i(c)` for the graph with
vertex set `V(X)` and edge set `{e ∈ E(X) : c(e) = i}`:

1. for every `i ∈ {0,…,k−1}`: `P( X_i(c) is an (ε′, s/(2k))-expander ) ≥ 1 − 2·N^{−5}`, and
2. `P( for all i, X_i(c) is an (ε′, s/(2k))-expander ) ≥ 1 − 2k·N^{−5}`,

where for `N = 0` the symbol `N^{−5}` is read as `0` (Lean's `zpow`).

This is the manuscript's statement with `[k]` replaced by `{0,…,k−1}` and with the case `N = 0`
added (see E1 below).

### Edge cases

* **E1, `N = 0` (vertexless graph).** Not covered by the manuscript ("N-vertex graph" and
  `log N`); Lean's `Real.logb 2 0 = 0` (checked: `by simp`) turns the hypothesis into `0 ≤ s`,
  and `(0 : ℝ) ^ (-5 : ℤ) = 0` (checked: `by simp`) makes both bounds `1 ≤ prob{…}`. Since
  `E(X) = ∅` (by `edge_verts`), the sample space is the single empty colouring, every `X_i` has no
  vertices, and `IsExpander` holds vacuously (no `U` with `1 ≤ |U| ≤ 0`), so both probabilities
  are `1` and the statement is true. The proof covers it (`FGraph.isExpander_of_card_le_one`).
  A true strengthening; harmless for locking.
* **E2, `N = 1`.** `Real.logb 2 1 = 0` (checked), hypothesis `0 ≤ s`, same as the manuscript's
  reading `L = 0`. `E(X) = ∅` again; every one-vertex graph is an expander; bounds `1 − 2 ≤ 1` and
  `1 − 2k ≤ 1`. Matches the manuscript's own treatment ("If N = 1 … nothing to prove").
* **E3, `N ≥ 2`.** `L ≥ 1`, so `s ≥ 40k ≥ 40 > 0`; all denominators (`log² N`, `2k`) are
  nonzero; `N^{−5} ≤ 1/32`, so the per-colour bound is at least `15/16` (scratch:
  `(15 : ℝ)/16 ≤ 1 - 2 * N^(-5)` for `N ≥ 2`). No Lean convention intervenes.
* **`ε′ ≤ 0`** is excluded by `0 < ε'`, as in the manuscript (and as CONVENTIONS.md requires,
  since `IsExpander` is trivial for `ε ≤ 0`). **`s < 0`** cannot occur under the hypotheses
  (`L ≥ 0` for every `N : ℕ`, so `s ≥ 0`).
* **`k`**: `NeZero k` makes `k ≥ 1`; `k = 1` gives the trivial colouring, where the conclusion
  reduces to monotonicity of expansion in `s` — true and covered by the proof.
* **`X` with no edges but `N ≥ 2`**: `X` is then not an `(ε′,s)`-expander (`U = {v}`, `F = ∅`),
  so the hypothesis fails; nothing to check. (Scratch: the edgeless 2-vertex graph is not an
  `(ε,s)`-expander for any `ε > 0`, `s ≥ 0`.)
* **Zero probabilities**: none appear; `randColouring` has full support.
* **ℕ subtraction**: none in the Spec (`1 - …` is real). **Rounding**: none (the manuscript's
  `m = ⌈ε′u/L²⌉` is proof-internal).
* **Typeclass/universe**: `V : Type u` for an arbitrary universe `u`, `[DecidableEq V]` for an
  arbitrary instance; `Fintype ↥X.edges` and `DecidableEq (Fin k)` are found by instance search
  and fixed at definition time. The proof is instance-agnostic and universe-polymorphic.

### Non-vacuity

* Hypotheses satisfiable with non-trivial content: take `X = K_N` (complete graph). For
  `1 ≤ u := |U| ≤ 2N/3` and `|F| ≤ su`, a vertex `w ∉ U` is missing from `Nbr_{K_N−F}(U)` only if
  all `u` edges from `w` to `U` lie in `F`; these edge sets are disjoint for distinct `w`, so at
  most `|F|/u ≤ s` vertices are missing and `|Nbr| ≥ N − u − s ≥ N/3 − s`. For `N ≥ 4`
  (`L² ≥ 4`) the requirement `ε′u/L² ≤ N/6` is met, so `K_N` is an `(ε′,s)`-expander for every
  `0 < ε′ ≤ 1` whenever `s ≤ N/6`. With `k = 2`, `N = 2^13`, `s = 80·13 = 1040 ≤ 8192/6`, all
  hypotheses hold and the colouring is genuinely random. (Not formalized — an `IsExpander` proof
  for `K_N` is a lemma in its own right; the argument is elementary.)
* Conclusion not trivially true: for `N ≥ 1` the bound `1 − 2N^{−5}` is `< 1` (scratch), and
  `IsExpander ε′ _` is a genuine constraint on graphs with `≥ 2` vertices (scratch, edgeless
  2-vertex graph), so the events are not the whole space for a formal reason.

## Notes for downstream Spec authors and reviewers (not defects; no change requested)

* **N1 (two bounds).** The per-colour bound is `1 − 2N^{−5}`; the bound for all classes at once
  is `1 − 2kN^{−5}`. All three manuscript uses I read (T16* Step 1 with `K_*` colours, s3.tex
  l. 826–832; COL stages (i)–(iii) with `k = 2`, `k`, `k_own`, l. 1364–1380; the levels table,
  l. 1204–1208) use the joint bound `2kN^{−5}` (e.g. "except with probability at most `4N^{−5}`"
  for `k = 2`), which is the Spec's second conjunct. Do not paraphrase the lemma as "with
  probability `≥ 1 − 2N^{−5}` every class is an expander".
* **N2 (colours are `Fin k`, 0-based).** `[k]` of the manuscript is `Fin k`; a named colour
  family needs an explicit bijection (CONVENTIONS.md, Probability).
* **N3 (`NeZero k`).** A downstream statement with a variable `k` and hypothesis `1 ≤ k` must
  supply `NeZero k` (e.g. `⟨by omega⟩`) to apply `l15p`; for literals `k = 2` the instance exists.
* **N4 (`decide` instance hygiene).** The Spec's `decide (c e = i)` elaborates with
  `instDecidableEqFin k`. A downstream file that writes the class under `classical` may get a
  different `Decidable` instance; the two are propositionally, not definitionally, equal
  (`Subsingleton (Decidable p)`). Writing `X.colourClass c i` (or the Spec's expression outside
  `classical`) avoids this.
* **N5 (colouring drawn jointly with other randomness).** The Spec's sample space is
  `randColouring X.edges k` alone. T16* Step 1 colours "uniformly and independently of V", and COL
  colours "given" an earlier stage. The proof file already provides the transports
  `l15p_of_map_eq` (any `μ` with `μ.map c = randColouring X.edges k`) and `l15p_prod_fst`
  (product with an independent second coordinate); these are theorems, not Spec content.
* **N6 (`N = 0`).** The Spec is true and proved at `N = 0` although the manuscript does not state
  it; downstream Specs need not exclude the vertexless graph before applying `l15p`.
