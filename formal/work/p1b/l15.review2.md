## 1. Fidelity

### Back-translation of `EG.Spec.L15pStatement` (from `#print`, scratch `Checks.lean`)

For every type `V` with decidable equality, every finite simple graph `X` on `V`, reals `ε'` and
`s`, and every natural number `k ≠ 0`, the following holds. Put `N = |V(X)|`. Assume `0 < ε'`,
`ε' ≤ 1`, `40·k·log₂N ≤ s`, and that `X` is an `(ε', s)`-expander in the sense of Def. 11
(`n = N`, `log = log₂`). Let `c` be a uniformly random map from the edge set `E(X)` to
`{0,…,k−1}`, so each edge gets an independent uniform colour; every colouring has weight
`k^{−|E(X)|}` (checked in `Checks.lean` (b)). For each colour `i`, let `X_i` be the graph with
vertex set `V(X)` whose edges are the edges `e ∈ E(X)` with `c(e) = i`, as checked in
`Checks.lean` (c). Then:

- (a) for every `i`, `P(X_i is an (ε', s/(2k))-expander) ≥ 1 − 2N^{−5}`;
- (b) `P(for all i, X_i is an (ε', s/(2k))-expander) ≥ 1 − 2kN^{−5}`.

### Comparison with the manuscript

> integer with `s≥40kL`. Give every edge of `X` a colour from `[k]`, independently and uniformly
> at random, and for `i∈[k]` let `X_i` be the graph with vertex set `V(X)` whose edges are the
> edges of colour `i`. Then for each `i∈[k]`, `X_i` is an `(ε′,s/(2k))`-expander with probability
> at least `1−2N^{−5}`. Hence all `k` classes are `(ε′,s/(2k))`-expanders with probability at

### Size condition on `N`

I found none, either in the lemma or in the section conventions (s3.tex lines 27–38). The
manuscript's proof handles `N = 1` separately and otherwise uses `N ≥ 2`. The Spec adds no size
condition, which is correct.

### Edge cases

- `N = 0`: here `0^{(−5:ℤ)} = 0` (checked in `Checks.lean` (d)), so the Spec claims
  probability `≥ 1`. That is true, since no `U` is admissible. The manuscript's `N^{−5}` is
  undefined at `N = 0`, so on this case the Spec is a strengthening.
- `N = 1`: `L = 0`, and the Spec agrees with the manuscript ("nothing to prove").
- `k = 1`: `X_0 = X`. The claim is consistent.
- The Spec never allows `ε' ≤ 0`. This matters, because `isExpander_of_nonpos` makes every
  graph an expander when `ε ≤ 0`, which would trivialise the statement.

### Task paraphrase vs manuscript

The task text reads "with probability `≥ 1 − 2N⁻⁵` every colour class …". The manuscript's
bound for all classes at once is `1 − 2kN^{−5}`, and `1 − 2N^{−5}` is the per-class bound. The
Spec follows the manuscript and states both. I agree with the author and with round 1.

- s4.tex line 165 ("each class fails with …") uses the per-class bound: the first conjunct.

## 4. The proof proves the Spec

`example : EG.Spec.L15pStatement.{0} := EG.l15p` and the same with `.{2}` both typecheck
(`Checks.lean` (a)). The proof follows the manuscript:

- **Step 1** (`step1`): suppose `U` is admissible and `|T| < ε'u/L²`. Applying Def. 11 with
  `F = E_X(U, 𝒩∖T)` gives `s u < e_X(U, 𝒩∖T)`. The manuscript's condition `|T| ≤ m−1` with
  `m = ⌈ε'u/L²⌉` is the same condition for an integer `|T|`.
- **Step 2** (`step2`): take `T := Nbr_{X_i−F}(U) ⊆ Nbr_X(U)`. The colour-`i` edges of
  `cross X U T` inject into `F`, so there are at most `s'u` of them.
- **Step 3** (`prob_step3_le`): this applies the Lib Chernoff lemma with `m = |cross|/k`, so
  `P(Z < m/2) ≤ e^{−m/8}`. Next, `|cross| = e_X(U,𝒩∖T) > su ≥ 40kLu` gives
  `e^{−m/8} ≤ e^{−5uL}`. Finally `7 ln 2 < 5` gives `e^{−5uL} ≤ N^{−7u}`. The event inclusion
  `{Z ≤ su/(2k)} ⊆ {Z < μ_Z/2}` is proved in `hsub`, as in the manuscript.
- **Step 4**: each `U` has at most `N^u` sets `T`, because each `T` has `|T| < u` and the
  number of such subsets is `∑_{j<u} C(N,j) ≤ ∑_{j<u} N^j < N^u`. The sum over nonempty `U` is
  then `(1+N^{−6})^N − 1 ≤ e^{N^{−5}} − 1 ≤ 2N^{−5}`. This replaces the manuscript's
  `∑_u N^{2u}N^{−7.2u}` with a sharper count and gives the same bound, as design-note deviation
  2 records. The case `N ≤ 1` goes through `isExpander_of_card_le_one`.
- **Conclusions**: the first conjunct comes from `prob_add_prob_compl`. The second comes from
  `prob_biInter_ge` summed over `Fin k`. The final `show` restates the Spec's exact goal and
  holds by `rfl`.

I rechecked the manuscript's arithmetic:
- `5·log₂e ≈ 7.213 ≥ 7.2`.
- For `N ≥ 2`, `N^{−5.2}/(1−N^{−5.2}) ≤ 2N^{−5}`.
- `∑_{j<m}N^j ≤ N^m` for `N ≥ 2`.

The proof itself uses only the weaker `7 ln 2 ≤ 5`, which follows from `Real.log_two_lt_d9`.
