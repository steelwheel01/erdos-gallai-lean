## 1. Fidelity: back-translation

Output of `#print EG.Spec.L15pStatement`:

```
∀ (V : Type u) [DecidableEq V] (X : FGraph V) (ε' s : ℝ) (k : ℕ) [NeZero k],
  0 < ε' → ε' ≤ 1 → 40 * ↑k * Real.logb 2 ↑X.card ≤ s → X.IsExpander ε' s →
  (∀ (i : Fin k), 1 - 2 * ↑X.card ^ (-5) ≤
     (FinDist.randColouring ↥X.edges k).prob
       {c | (X.restrictEdges (FinDist.selectSet X.edges fun e => decide (c e = i))).IsExpander
              ε' (s / (2 * ↑k))}) ∧
  1 - 2 * ↑k * ↑X.card ^ (-5) ≤
     (FinDist.randColouring ↥X.edges k).prob
       {c | ∀ (i : Fin k),
              (X.restrictEdges (FinDist.selectSet X.edges fun e => decide (c e = i))).IsExpander
                ε' (s / (2 * ↑k))}
```

In plain mathematics: let `X` be a finite simple graph on `N := |V(X)|` vertices, and let `ε', s`
be reals and `k ≥ 1` an integer with `0 < ε' ≤ 1` and `40·k·log₂N ≤ s`. Suppose `X` is an
`(ε',s)`-expander (Def. 11, with `log₂`). Colour each edge of `X` independently and uniformly with
a colour in `{0,…,k−1}`, and let `X_i` be the spanning subgraph (vertex set `V(X)`) whose edges
are the edges of colour `i`. Then (a) for every `i`, `P(X_i is an (ε', s/(2k))-expander) ≥ 1 −
2N^{−5}`; and (b) `P(every X_i is an (ε', s/(2k))-expander) ≥ 1 − 2kN^{−5}`.

The manuscript statement (s3.tex, lines 100–108) is: "Let `X` be an `N`-vertex
`(ε′,s)`-expander with `0<ε′≤1`, put `L:=log N`, and let `k≥1` be an integer with `s≥40kL`. Give
every edge of `X` a colour from `[k]`, independently and uniformly at random, and for `i∈[k]` let
`X_i` be the graph with vertex set `V(X)` whose edges are the edges of colour `i`. Then for each
`i∈[k]`, `X_i` is an `(ε′,s/(2k))`-expander with probability at least `1−2N^{−5}`. Hence all `k`
classes are `(ε′,s/(2k))`-expanders with probability at least `1−2kN^{−5}`." The quote in the
Spec docstring is verbatim.

Quantifiers, inequality directions, the log base and the constants (40, 2, 5, `2k`) all match. The
statement quantifies over every `DecidableEq V` instance and every universe `u`, which is at
least as strong as the manuscript.

**Edge cases.**
- `N = 1`: `L = 0`, and Def. 11 is vacuous (no `U` has `1 ≤ |U| ≤ 2/3`). Both sides agree, as
  the manuscript's proof says.
- `N = 0`: the manuscript does not cover this case (`N^{−5}` is undefined). In Lean
  `0^(−5) = 0`, so the Spec claims probability `≥ 1`. That is true (there is no admissible `U`),
  and it is a strengthening, not a weakening.
- `k = 1`: `X_0 = X`, and `(ε',s)`-expander implies `(ε',s/2)`-expander. Consistent.
- `s`: the manuscript implicitly takes `s ≥ 0`, and the hypothesis gives `s ≥ 40kL ≥ 0`
  whenever `N ≥ 1`.

**Size condition on `N`.** The manuscript has none. Its proof treats `N = 1` separately and
otherwise uses `N ≥ 2`. The Spec adds none. Correct.

**Task paraphrase vs manuscript.** The task text says "with probability ≥ 1 − 2N⁻⁵ every colour
class is an expander". The manuscript's per-colour bound is `1 − 2N^{−5}`, and its bound for all
colours at once is `1 − 2kN^{−5}`. The Spec follows the manuscript and states both, and the
design note flags the discrepancy. I agree with the author. The downstream use (T16*, Step 1:
"with probability at least `1−2K_*N^{−5}`, every `X_i` is an `(ε′,s/(2K_*))`-expander")
matches the second conjunct.

**Auxiliary definitions in the Spec.** There are none. The Spec inlines
`restrictEdges`/`selectSet`. The proof's `L15.colourClass` is `@[expose]` and definitionally equal
to that expression. It is only a name inside the proof, so no weakening can hide behind it: the
kernel checks `l15p : EG.Spec.L15pStatement`.

## 2. Vacuity

- **The hypotheses can be satisfied non-trivially with `N ≥ 2`.** For `ε' > 0` and `N ≥ 2`,
  Def. 11 forces `δ(X) > s ≥ 40kL ≥ 40`, so `N ≥ 42`. A natural worry is that the hypotheses
  could only hold for `N ≤ 1`. In my scratch file `Witness.lean` I proved:
  - `complete_nbr_ge`: in `K_n` on `Fin n`, `|Nbr_{K_n−F}(U)| ≥ n − |U| − s` whenever
    `|U| ≥ 1` and `|F| ≤ s|U|`. The proof double-counts `U × B → F`, where `B` is the set of
    outside vertices cut off from `U`.
  - `K2048_isExpander : (ofSimpleGraph (⊤ : SimpleGraph (Fin 2048))).IsExpander 1 440`, with
    `log₂ 2048 = 11`.
  - `hyp_s : 40·1·log₂ 2048 ≤ 440`, and the same with `k = 2`, `s = 880`.
  - `EG.l15p (Fin 2048) (ofSimpleGraph ⊤) 1 440 1 one_pos le_rfl hyp_s K2048_isExpander`
    elaborates, and the resulting bound `1 − 2·2048^{−5}` is positive.

  So the Spec applies to a genuine expander with `N ≥ 2` and gives a nontrivial bound.
- **The conclusion is not a tautology.** In `NotTaut.lean` I proved `conclusion_fails`. Take
  `K₂` on `Fin 2`, `k = 2`, `ε' = 1`, `s = 1/2`. `K₂` is a `(1, 1/2)`-expander (`EGTest`), but
  `s ≥ 40kL` fails. For this graph the first conjunct fails:
  `P(X_0 is a (1, 1/8)-expander) ≤ P(c(01) = 0) = 1/2 < 1 − 2·2^{−5}`. So the Spec's conclusion
  depends on the hypotheses and does not hold for free.
- The hypotheses are not contradictory, and no hypothesis makes the conclusion trivially true.

## 4. The proof proves the Spec

`EG.l15p : EG.Spec.L15pStatement.{u}`, checked with `#check`. The structure follows the manuscript:

- **Step 1** (`step1`): if `1 ≤ |U| ≤ 2N/3`, `U ⊆ V(X)` and `|T| < ε'|U|/L²`, then
  `s|U| < e_X(U, Nbr_X(U) \ T)`. This uses the expansion of `X` with
  `F = E_X(U, Nbr_X(U) \ T)`, as in the manuscript. The formal proof writes `|T| ≤ m−1` with
  `m = ⌈ε'u/L²⌉` as `|T| < ε'u/L²`, which is equivalent for an integer `|T|`.
- **Step 2** (`step2`): a failure of `X_i` gives `U`, and `T := Nbr_{X_i−F}(U) ⊆ Nbr_X(U)` with
  `#{e ∈ E_X(U, Nbr_X(U)\T) : c e = i} ≤ s'|U|` (via an injection into `F`). Faithful.
- **Step 3** (`prob_step3_le`): the lower Chernoff bound with `δ = 1/2` and `m = e/k`, where
  `e = |cross| = e_X(U,𝒩\𝒯)`. Then `e^{−e/(8k)} ≤ e^{−5uL}` (from `e > su` and `s ≥ 40kL`), and
  `e^{−5uL} ≤ N^{−7u}` (from `7 ln 2 < 5`, via `Real.log_two_lt_d9`). The event
  `{Z ≤ su/(2k)}` is contained in `{Z < μ_Z/2}`, as in the manuscript; this is done in `hsub`.
- **Step 4**: the count `|𝒯(U)| ≤ N^{|U|}` is as in the manuscript (`∑_{j<u} C(N,j) ≤
  ∑_{j<u} N^j < N^u`, needing `N ≥ 2`). The sum over `U` is exact:
  `∑_{∅≠U⊆V(X)} N^{|U|}·N^{−7|U|} = (1+N^{−6})^N − 1 ≤ e^{N^{−5}} − 1 ≤ 2N^{−5}`. This is a
  valid variant of the manuscript's `∑_u N^{2u}N^{−7.2u}`; the design note records it as
  deviation 2. The case `N ≤ 1` is handled by `isExpander_of_card_le_one`.
- **Conclusions**: the per-colour bound comes from the complement, and the all-colours bound
  from `prob_biInter_ge` summed over `Fin k`. Both match the Spec exactly.

I also rechecked the manuscript's arithmetic: `5·log₂e ≈ 7.21 ≥ 7.2`, and for `N ≥ 2`,
`N^{−5.2}/(1−N^{−5.2}) ≤ 2N^{−5.2} ≤ 2N^{−5}`. It is correct.
