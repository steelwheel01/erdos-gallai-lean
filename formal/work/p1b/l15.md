## The statement (faithful reading)
Manuscript s3:lemL15p: "Let X be an N-vertex (ε′,s)-expander with 0<ε′≤1, put L:=log N, and let
k≥1 be an integer with s≥40kL. Give every edge of X a colour from [k], independently and uniformly
at random, and for i∈[k] let X_i be the graph with vertex set V(X) whose edges are the edges of
colour i. Then for each i∈[k], X_i is an (ε′,s/(2k))-expander with probability at least 1−2N^{−5}.
Hence all k classes are (ε′,s/(2k))-expanders with probability at least 1−2kN^{−5}."

```lean
def L15pStatement : Prop :=
  ∀ (V : Type u) [DecidableEq V] (X : EG.FGraph V) (ε' s : ℝ) (k : ℕ) [NeZero k],
    0 < ε' → ε' ≤ 1 → 40 * (k : ℝ) * Real.logb 2 (X.card : ℝ) ≤ s → X.IsExpander ε' s →
    (∀ i : Fin k,
      1 - 2 * (X.card : ℝ) ^ (-5 : ℤ) ≤
        (EG.FinDist.randColouring X.edges k).prob
          {c | (X.restrictEdges (EG.FinDist.selectSet X.edges fun e => decide (c e = i))).IsExpander
            ε' (s / (2 * (k : ℝ)))}) ∧
    1 - 2 * (k : ℝ) * (X.card : ℝ) ^ (-5 : ℤ) ≤
      (EG.FinDist.randColouring X.edges k).prob
        {c | ∀ i : Fin k, (X.restrictEdges (…)).IsExpander ε' (s / (2 * (k : ℝ)))}
```

- `N = X.card`, `L = Real.logb 2 N` (log₂, s1:convGraphs (b)); `ε' s : ℝ`; `k : ℕ` with
  `[NeZero k]` for "k ≥ 1" (`randColouring` needs `NeZero`).
- The random colouring is `FinDist.randColouring ↥X.edges k` (uniform product over the edge
  finset, colours `Fin k` in place of `[k]`), exactly as the FinDist design note intends.
- `X_i` is `X.restrictEdges (selectSet X.edges fun e => decide (c e = i))`: vertex set `V(X)`,
  edges the edges of colour `i` (the representation of `map_selectSet_randColouring`). No new
  definition in the Spec file; the proofs name it `EG.FGraph.colourClass X c i` (shared
  `@[expose]` definition in `EG/Lib/Found/ColourClass.lean`, equal to the Spec expression by
  `rfl`, `FGraph.colourClass_eq`).
- `N^{−5}` is `(N : ℝ) ^ (-5 : ℤ)`.
- Both conclusions of the manuscript are stated (the per-colour bound and the all-colours bound).
- **Size condition on N: none in the manuscript** (its proof treats N = 1 separately: no `U`
  satisfies `1 ≤ |U| ≤ 2N/3`). None is added. For `N = 0` Lean reads `0^(-5) = 0` and the
  statement holds for the same reason (every graph without vertices is an expander).
- **Remark on the task text.** The task description paraphrases the conclusion as "with
  probability ≥ 1 − 2N⁻⁵ every colour class is an expander". That is not what the manuscript says:
  the bound `1 − 2N^{−5}` is per colour, and the bound for all `k` classes simultaneously is
  `1 − 2kN^{−5}`. The statement follows the manuscript.

## Proof structure (`EG/Proof/Link/L15.lean`, namespace `EG.L15`)
- Colour classes: `FGraph.colourClass` and `FGraph.colourClass_verts/card/le`,
  `FGraph.coe_mem_colourClass_edges` (an edge lies in `X_i` iff its colour is `i`), from
  `EG/Lib/Found/ColourClass.lean` (until fix round 1 these were proof-local in `EG.L15`).
- `cross X U T : Finset ↥X.edges`: the edges of `X` between `U` and `Nbr_X(U) \ T` as
  coordinates of the colouring; `card_cross : |cross| = e_X(U, Nbr_X(U) \ T)`.
- `step1` (Step 1): `U ⊆ V(X)`, `1 ≤ |U| ≤ 2N/3`, `|T| < ε′|U|/L²` ⇒ `s|U| < e_X(U, 𝒩 \ T)`.
- `step2` (Step 2): if `X_i` is not an `(ε′,s′)`-expander, there are `U` (as above) and
  `T ⊆ Nbr_X(U)` with `|T| < ε′|U|/L²` and `#{e ∈ cross X U T | c e = i} ≤ s′|U|`
  (`T := Nbr_{X_i−F}(U)`).
- `prob_step3_le` (Step 3): Chernoff via `FinDist.chernoff_randColouring_lower_half` (already
  present in `EG/Lib/Prob/Chernoff.lean`, so **no `l15_chernoff_aux` sorry was needed**), then
  `e^{−μ/8} ≤ e^{−5uL} ≤ N^{−7u}`.
- `exp_neg_five_mul_logb_le`: `e^{−5uL} ≤ (N⁻¹)^{7u}` for `N ≥ 1` (from `7 ln 2 ≤ 5`).
- `card_powerset_filter_card_lt_le`: at most `N^u` subsets of a set of `≤ N` elements have
  fewer than `u` elements (`∑_{j<u} C(N,j) ≤ ∑_{j<u} N^j < N^u`, `N ≥ 2`).
- `sum_powerset_erase_pow_le`: `∑_{∅≠U⊆S} (N^{−6})^{|U|} = (1+N^{−6})^N − 1 ≤ e^{N^{−5}} − 1 ≤
  2N^{−5}`.
- `prob_not_isExpander_colourClass_le` (Steps 1–4): `P(X_i not an (ε′,s/(2k))-expander) ≤
  2N^{−5}`; union bound over `U ∈ 𝒰` and `T ∈ 𝒯(U)` with `FinDist.prob_biUnion_le`.
- `EG.l15p`: the Spec statement (per-colour bound by complement; all colours by
  `prob_biInter_ge` and summing the per-colour bound over `Fin k`).
- `EG.exists_colouring_forall_isExpander` (convenience corollary for downstream users, no
  manuscript label): if `2kN^{−5} < 1`, some colouring of positive weight has all classes
  `(ε′,s/(2k))`-expanders.
- `EG.l15p_of_map_eq` (transport, no manuscript label): for any `μ : FinDist Ω` and
  `c : Ω → (↥E(X) → Fin k)` with `μ.map c = randColouring X.edges k`, both bounds of the Spec
  hold for `μ.prob {ω | … X.colourClass (c ω) i …}` (proof: `prob_map`). `EG.l15p_prod_fst`: the
  instance `μ = (randColouring X.edges k).prod ν`, `c = Prod.fst` (`map_fst_prod`), i.e. a colouring
  drawn independently of a second random object (T16* Step 1).

## Deviations from the manuscript's proof (the statement is unchanged)
1. `|T| ≤ m − 1` with `m = ⌈ε′u/L²⌉` is written as the equivalent `(|T| : ℝ) < ε′u/L²`; no
   ceiling is used.
2. Step 4: the manuscript uses `e^{−5uL} ≤ N^{−7.2u}` and bounds the number of sets `U` of size
   `u` by `N^u`. Here `e^{−5uL} ≤ N^{−7u}` is used and the sum over `U` is computed exactly by
   the binomial theorem, `∑_{U≠∅} (N^{−6})^{|U|} = (1+N^{−6})^N − 1 ≤ 2N^{−5}`. The bound on the
   number of sets `T` (`≤ N^u`) is the manuscript's.
3. Step 1 does not need `T ⊆ 𝒩`; Step 2 still produces `T ⊆ 𝒩` (used for the count of `T`s).
