### s4:lemTPV — `TPVStatement`

**TeX (s4.tex:159–200, abridged; the full quote is in the file docstring).**

> Let `Z` be a set of `N ≥ N_0` vertices and `L := log₂N`. Let `O` be a spanning `(ε_O,s)`-expander
> on `Z` with `ε_O ∈ [2^{-7},2^{-5}]` (only `ε_O ≥ 2^{-7}` is used in the proof) and
> `s ≥ 2^{150}L^{42}`, and let `Z = P ⊔ Q` be a partition.
>
> [Parameters `J, k, m, b, t`; the family `A(w)`; the labels (a) colouring, (b) levels, (c) `κ`; the
> sets `U_j, W_j, Z_j, V_{j,c}`.]
>
> There is an event `𝒢_TPV`, determined by `(Z,O,P)` and the labels only, with
> `P(𝒢_TPV) ≥ 1/2 − η_TPV(N)`, where `η_TPV(N) ≤ 1/100`, such that on `𝒢_TPV` the following holds
> for *every* edge set `E` with `E(O) ⊆ E` all of whose edges have both ends in `Z`: there is a
> partition `E = E^V ⊔ E^Q` with
> - (T1) every edge of `E` with both ends in `P` lies in `E^V`;
> - (T2) every edge of `E^V` with an end in `Q` is an edge of `O`;
> - (T3) `E^V` decomposes into at most `169|P|` objects, and `E^V = ∅` if `P = ∅`;
> - (T4) (no arcs) all objects of (T3) consist of edges of `E`; … the run leaves no path ("arc") to
>   be closed by any other device.
>
> The partition and the decomposition are obtained from `E` and the labels by a deterministic
> procedure.

**Lean.**

```lean
TPVStatement := ∀ V [DecidableEq V] (Z : Finset V) (O : FGraph V) (P : Finset V) (εO s : ℝ),
  TPVHyp Z O P εO s → ∀ E, TPVAdm Z O E → TPVConcl Z O P E
```

**Back-translation.** Let `Z` be a finite vertex set with `N = |Z|` and `L = log₂ N`, and assume the
following:
- `N` satisfies the size conditions (i) `L ≥ 2^{10}`, (ii) `N ≥ L^3` and (iv) `η_TPV(N) ≤ 1/100`;
- `O` is a graph with `V(O) = Z` that is an `(ε_O, s)`-expander, where `2^{-7} ≤ ε_O ≤ 2^{-5}` and
  `2^{150} L^{42} ≤ s`;
- `P ⊆ Z`, and `Q := Z \ P`.

Then for every loopless edge set `E` whose edge ends all lie in `Z` and with `E(O) ⊆ E`, there are
disjoint `E^V`, `E^Q` with `E^V ∪ E^Q = E` such that:
- (T1) every edge of `E` all of whose ends lie in `P` is in `E^V`;
- (T2) every edge of `E^V` with an end in `Z \ P` is an edge of `O`;
- (T3) there is a list of objects that decomposes `E^V` exactly and has length at most `169|P|`;
- `P = ∅` implies `E^V = ∅`.

### s4:thmVXp — `VXStatement`

**TeX (s4.tex:645–675, abridged; the full quote is in the file docstring).**

> Let `Z` be a set of `N ≥ N_0` vertices, `L := log₂N`, and let `O` be a spanning
> `(ε_O,s)`-expander on `Z`, where either `ε_O = 2^{-5}` and `s ≥ 2^{146}L^{38} log₂L`, or
> `ε_O = 2^{-6}` and `s ≥ 2^{151}L^{38} log₂L`.
>
> [Parameters and labels.]
>
> There is an event `𝒢_VX`, determined by `O` and the labels only, with
> `P(𝒢_VX) ≥ 1 − η_VX(N) ≥ 1/2`, such that on `𝒢_VX` the following holds simultaneously for
> *every* graph `G` with `V(G) = Z` and `E(O) ⊆ E(G)`: `E(G)` decomposes into at most
> `38.4N + 13N ≤ 52N ≤ 80N` objects, all of which are cycles except at most `N + 13N/L = N + o(N)`
> single edges. In particular `f(G) ≤ 80N`.

**Lean.**

```lean
VXStatement := ∀ V [DecidableEq V] (Z : Finset V) (O : FGraph V) (εO s : ℝ),
  VXSize Z.card → O.verts = Z → O.IsExpander εO s →
  ((εO = 2^(-5:ℤ) ∧ 2^146 * L Z.card^38 * logb 2 (L Z.card) ≤ s) ∨
   (εO = 2^(-6:ℤ) ∧ 2^151 * L Z.card^38 * logb 2 (L Z.card) ≤ s)) →
  ∀ G : FGraph V, G.verts = Z → O.edges ⊆ G.edges →
    (∃ D, IsDecomp ↑G.edges D ∧ (D.length : ℝ) ≤ 38.4 N + 13 N ∧
          (D.countP Obj.isEdge : ℝ) ≤ N + 13 N / L) ∧
    fnum G.edges ≤ 80 N
```

**Back-translation.** Let `Z` be a finite vertex set with `N = |Z|` and `L = log₂ N`, and assume the
following:
- `N` satisfies (i) `L ≥ 2^{10}`, (ii) `N ≥ L^3` and (iv) `η_VX(N) ≤ 1/100`;
- `O` is a graph with `V(O) = Z` that is an `(ε_O,s)`-expander, where either `ε_O = 2^{-5}` and
  `s ≥ 2^{146} L^{38} log₂ L`, or `ε_O = 2^{-6}` and `s ≥ 2^{151} L^{38} log₂ L`.

Then every simple graph `G` with `V(G) = Z` and `E(O) ⊆ E(G)` satisfies both of the following:
- there is a decomposition of `E(G)` into at most `38.4N + 13N` objects, at most `N + 13N/L` of
  which are single edges;
- `f(E(G)) ≤ 80N`.

## Hazards and choices (T0 decisions)

1. **Deterministic form (TPV-DET-SPEC, VX-DET-SPEC; TRIAGE §2.8, §2.12).** Both conclusions are
   label-free, and the good event has positive probability. For TPV the bound is
   `1/2 − η ≥ 1/2 − 1/100`, where `η ≤ 1/100` is part of `TPVSize`. For VX⁺ it is `≥ 1/2`.
   - So the TeX statement implies the Spec.
   - Conversely, the Spec gives the TeX statement with the good event equal to the whole label
     space. This needs `1 ≥ 1/2 − η` (and, for VX⁺, `1 − η_VX ≥ 1/2`, which is (iv)).
   - Given the hypotheses, the two forms are therefore equivalent.
   - Not stated, as for PV: the parameters, the labels, the explicit events (G1)–(G5) and their
     probabilities. These are proof internals (Lib). The meta-claims "determined by … and the labels"
     and "deterministic procedure" are also not stated.
2. **`N ≥ N_0` as a size predicate.** It is encoded as `TPVSize Z.card` / `VXSize Z.card` (TRIAGE
   §2.4, same as `PVHyp`).
   - `N_0` is defined so that these conditions hold (`N0Cond`), so `N0Cond N0 ∧ N0 ≤ N` implies the
     predicate. The Spec hypothesis is therefore no stronger than the TeX one.
   - The proofs state that they use only the size conditions (i)–(iv), and (iii) is derived.
   - Hazard for the prover: if a proof needs a further "N large" inequality that is not in the
     predicate, the predicate (a locked Def) is too weak. This is not a statement error.
3. **Partition `Z = P ⊔ Q`.** It is encoded as `P ⊆ Z` with `Q := Z \ P`. `P = ∅` and `P = Z` are
   both allowed, as in the TeX (the proof treats `P = ∅` separately).
4. **Admissible `E` (TPV).** An admissible `E` is loopless (CONVENTIONS "Objects and f": "edge set of
   a simple graph"), has all edge ends in `Z`, and satisfies `E(O) ⊆ E`. The loopless hypothesis is
   T0: s4 declares that all graphs are simple, and every consumer `E` is a subset of `E(G)`.
5. **(T4)** is not a separate conjunct.
   - "All objects consist of edges of `E`" follows from `IsDecomp ↑EV D` and `EV ⊆ E`.
   - "No arc is left" says that the procedure's only output on `E^V` is the object list, which
     `IsDecomp` (exact cover) expresses.
6. **Parameter ranges (TPV).** Both bounds `2^{-7} ≤ ε_O ≤ 2^{-5}` are kept, although the TeX notes
   that only the lower bound is used. Dropping the upper bound would strengthen the Spec. Keeping it
   is faithful. A consumer whose `ε_O` exceeds `2^{-5}` could not apply the Spec; the consumer
   authors (MIX-C) should confirm that their `ε_O` lies in `[2^{-7},2^{-5}]`.
7. **VX⁺ count.** The Spec takes `38.4N + 13N`, the strongest bound in the displayed chain
   "`38.4N + 13N ≤ 52N ≤ 80N`". The blueprint proposed `≤ 52N`, which would weaken the statement.
   - The proof gives `Σ_{j<J} 19·1.01·2^{-j}N + 13N < 38.38N + 13N`, so the literal bound is the
     one proved.
   - The single-edge bound `N + 13N/L` and `f(G) ≤ 80N` are both stated. `f ≤ 80N` follows from the
     count bound, since `51.4 ≤ 80`.
   - `38.4` is a real literal (`OfScientific ℝ`).
8. **VX⁺ graph `G`.** `G : FGraph V` (simple: loopless, edges inside `verts`), with
   `G.verts = Z` and `O.edges ⊆ G.edges`.
   - The consumer s5:lemDemoted (`LemDemotedStatement`, bound `80|Y|` for every `E` with
     `E(X_Y) ⊆ E ⊆ E_r(Y)`) builds `G := ⟨V(Y), E, …⟩`.
   - It uses the `fnum` conjunct, or the count conjunct together with `51.4 ≤ 80`.
9. **Consumer form of TPV (TRIAGE §2.8; blueprint s6b `S4.TPVGood`/`S4.TPVHyps`,
   `MixCTPVApplicable`).**
   - The named Defs `TPVHyp` / `TPVAdm` / `TPVConcl` are exported so that MIX-C and s7:lemOneOutcome
     can state the TPV bullet at `(Z^0_Z, O_Z, Ret_Z)` without copying.
   - Applicability is `∃ εO s, TPVHyp Z O P εO s`.
   - The conclusion predicate is `∀ E, TPVAdm Z O E → TPVConcl Z O P E`. It differs from the s6b
     draft `TPVGood` only by the loopless hypothesis on `E`, which every consumer `E ⊆ E(G)` meets,
     and by the extra conjunct `P = ∅ → EV = ∅`.
   - No MIX-C Spec exists yet (`EG/Spec/Chain/` has no `MixC.lean`), so no consumer file needed
     adapting.
