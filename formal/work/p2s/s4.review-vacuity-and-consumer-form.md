## 2. Vacuity

### 2.1 Hypotheses are consistent (not contradictory)

- `TPVSize`, `VXSize` are satisfiable: `EGTest/Spec_s4.lean` (`eventually_size`).
- `TPVAdm Z O E` is satisfiable with `E = O.edges` (test file).
- The expander hypotheses together with the size predicates are satisfiable, on paper (not in Lean;
  the test file says so). Take `N = 2^{2^{10}}`, so `L = 2^{10}` exactly, and `O = K_N` on `Z`.
  `TPVSize`/`VXSize`: (i) `L = 2^{10}` ✓; (ii) `L^3 = 2^{30} ≤ N` ✓; (iv) each term of
  `η_TPV`, `η_VX` is below `2^{-1000}` ✓. Expander: for `U ⊆ Z`, `1 ≤ |U| ≤ 2N/3`, `F ⊆ E(K_N)`,
  `|F| ≤ s|U|`: a vertex `v ∉ U` is outside `Nbr_{K_N − F}(U)` only if all `|U|` edges from `v` to
  `U` lie in `F`, so at most `|F|/|U| ≤ s` vertices are lost and
  `|Nbr_{K_N−F}(U)| ≥ N − |U| − s ≥ N/3 − s`, while `ε|U|/L² ≤ 2^{-5}(2N/3)/L² = N/(48L²)`. So
  `K_N` is an `(ε, s)`-expander for every `ε ≤ 2^{-5}` and `s ≤ N/3 − N/(48L²)`; here
  `s = 2^{150}L^{42} = 2^{570}` (TPV) or `s = 2^{151}L^{38}·10 < 2^{535}` (VX⁺) against
  `N/3 ≈ 2^{1022}`. Hence `TPVHyp Z K_N P εO s` holds for every `P ⊆ Z`, both `εO ∈ {2^{-7}, 2^{-5}}`,
  and the VX⁺ hypotheses hold in both regimes. Not contradictory (issue 4 records that this is
  paper-only).
- `TPVHyp` never lands in the trivial `IsExpander` cases (checks 4, 5).

### 2.2 Conclusions are not trivially true

- `TPVConcl Z O P E` for `P ≠ ∅`: the witness `EV = ∅` violates (T1) as soon as `E` has an edge
  inside `P`; the witness `EV = E` violates (T2) as soon as `E \ E(O)` has an edge meeting `Q`; and
  (T3) demands a decomposition of `EV ⊇ E[P]` into `O(|P|)` objects, which for an arbitrary graph on
  `P` is the content of the conjecture itself (check 2: with `P = Z` the Spec says every graph
  containing `O` has `f ≤ 169N`). So the conclusion has content and is only trivial in the cases the
  TeX also treats trivially (`P = ∅`: the test file; `E = ∅`).
- `VXStatement`'s conclusion for a graph `G ⊇ O` on `N` vertices: `f(G) ≤ 80N` is a linear
  absorption bound for every supergraph of `O`; not trivial (the trivial bound is `|E(G)| ≤ N²/2`).
  The single-edge conjunct is on the same `D`, so it cannot be discharged separately.
- Both conclusions are satisfiable for the extreme inputs (test file: `P = ∅`, `E = ∅`, edgeless
  `G`), so nothing is contradictory by encoding.

### 2.3 Deterministic form does not hide a vacuity

The TeX has `∃ 𝒢, P(𝒢) ≥ 1/2 − η, ∀ labels ∈ 𝒢, ∀ E, …`; with a label-free inner statement this is
`∀ E, …` provided `P(𝒢) > 0`, which needs `η_TPV(N) < 1/2` — guaranteed by (iv) `η ≤ 1/100` inside
`TPVSize`. If (iv) were absent the two forms would still be equivalent whenever the TeX lemma is
true, but the Spec would then assert something the TeX proof does not prove for small `N`; (iv) is
present, so there is no gap. Same for VX⁺ with `1 − η_VX ≥ 1/2`.
