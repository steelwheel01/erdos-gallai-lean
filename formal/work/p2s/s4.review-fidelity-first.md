### s4:lemTPV (`EG.Spec.TPVStatement`, Defs `TPVHyp`, `TPVAdm`, `TPVConcl`)

Back-translation. Let `Z` be a finite set with `N = |Z|` and `L = log₂N`. Assume:
- `L ≥ 2^10`, `N ≥ L^3` and `η_TPV(N) ≤ 1/100`;
- `O` is a graph with `V(O) = Z` that is an `(ε_O,s)`-expander;
- `2^{-7} ≤ ε_O ≤ 2^{-5}` and `2^{150}L^{42} ≤ s`;
- `P ⊆ Z`.

Then for every loopless finite edge set `E` with all ends in `Z` and `E(O) ⊆ E`, there are disjoint
`E^V`, `E^Q` with `E^V ∪ E^Q = E` such that:
- every edge of `E` with both ends in `P` is in `E^V`;
- every edge of `E^V` with an end in `Z \ P` is in `E(O)`;
- some object list `D` satisfies `IsDecomp E^V D` and `|D| ≤ 169|P|`;
- `P = ∅` implies `E^V = ∅`.

Comparison with the TeX (s4.tex:159–196):

### s4:thmVXp (`EG.Spec.VXStatement`)

Back-translation. Let `Z` be a finite set with `N = |Z|` and `L = log₂N`. Assume:
- `L ≥ 2^{10}`, `N ≥ L^3` and `η_VX(N) ≤ 1/100`;
- `V(O) = Z` and `O` is an `(ε_O,s)`-expander;
- either (`ε_O = 2^{-5}` and `2^{146}L^{38}log₂L ≤ s`) or (`ε_O = 2^{-6}` and `2^{151}L^{38}log₂L ≤ s`).

Then for every simple graph `G` with `V(G) = Z` and `E(O) ⊆ E(G)`, both of the following hold:
- some object list `D` exactly decomposes `E(G)` with `|D| ≤ 38.4N + 13N` (real), and the number of
  single-edge objects in `D` is at most `N + 13N/L` (real);
- `f(E(G)) ≤ 80N` (ℕ).

Comparison with the TeX (s4.tex:645–675):
- The quantifiers are in the TeX order. The two parameter pairs are an exact disjunction, and
  `2^{-5} ≠ 2^{-6}` (checked).
- `log₂L` is `logb 2 (L N)`.
- `38.4` is the real `192/5` (checked).
- The count and the single-edge bound hold for the same `D`, as the TeX says "all of which are
  cycles except at most …".
- The Spec keeps `38.4N + 13N`, the strongest bound in the displayed chain. I re-derived it:
  `Σ_{j<J} 19·1.01·2^{-j}N < 38.38N`, plus `13N` from EG0(b) with `β = 13`, `α = N`,
  `|U_J| < 1.01·12N/L ≤ 13N/L`.
- The single-edge bound `N + 13N/L` also checks: parity edges contribute `≤ Σ|W_j| ≤ N`, and the
  finish contributes `≤ |U_J|`.
- Deterministic form: `P(𝒢_VX) ≥ 1/2 > 0`, and the conclusion is label-free, so the two forms are
  equivalent.
- The consumer `LemDemotedStatement` uses `O := X_Y`, a `(2^{-6}, s_r/2)`-expander with
  `s_r/2 ≥ 2^{151}L^{38}log₂L` (s5.tex:332). That matches the second disjunct exactly. It then
  builds `G := (V(Y), E)` from `E ⊆ E_r(Y)`, whose edges lie inside `Y` (Structure (iii)), and uses
  `|D| ≤ 51.4N ≤ 80N` or the `fnum` conjunct.

## 2. Vacuity

- Hypotheses. There is no Lean witness yet (the author's test file says so). By hand, the complete
  graph `K_N` is a `(2^{-5}, N/6)`-expander:
  - with `|F| ≤ s|U|`, at most `s` outside vertices can lose all their edges to `U`;
  - so `|N(U)| ≥ N/3 − N/6`, which is at least `ε|U|/L²`.

  At `N = 2^{1024}` we have `TPVSize` and `VXSize` (TRIAGE §3.14), and `N/6 ≥ 2^{150}L^{42} = 2^{570}`
  and `N/6 ≥ 2^{146}L^{38}log₂L`. So `TPVHyp` (with any `P ⊆ Z`) and the VX hypotheses are
  satisfiable. They are not contradictory.
- Conclusions. They are not trivially true:
  - For TPV with `P = Z`, `E^V = E` is forced (proved in the scratch file). So the conclusion asks
    for a decomposition of every `E ⊇ E(O)` into `≤ 169N` objects, which single edges cannot give
    once `|E| > 169N`.
  - For VX⁺, `D` has at most `N + 13N/L` single edges and at most `51.4N` objects in all. This
    cannot hold trivially for dense `G`.
  - They are also not contradictory by encoding: the author's tests cover `P = ∅`, `E = ∅` and an
    edgeless `G`.
