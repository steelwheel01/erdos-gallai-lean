### The proof used (count-only; no literature source available offline)

Notation: `E` a loopless finite edge set, `V(E)` its vertices (`edgeVerts`), a PC-decomposition is
`IsPathCycleDecomp E P C`, its size `|P|+|C|`; an *end* of `v` is a path of `P` with `v` as first
or last vertex (`pathEndCount P v`).

1. Parity (existing `Cor22.even_degE_add_pathEndCount`): if `deg_E v` is odd, `v` is an end of
   some path.
2. Pendant removal: if `ℓ` has exactly one edge `xℓ` in `E`, a PC-decomposition of `E` gives one of
   `E − xℓ` of no larger size (the path through `xℓ` has `ℓ` as an end; drop `ℓ`).
3. Attachment lemma (AL). Let `x` be a vertex, `B` a set of vertices with `xb ∉ E` (`b ∈ B`), and
   `(P,C)` a PC-decomposition of `E` in which every neighbour of `x` in `E ∪ xB` is an end of some
   path. Then `E ∪ xB` has a PC-decomposition of the same size.
   Proof. For a path `p ∈ P` through `x`, `p = L ++ x :: R`; the *arm* at `u = R.head` is `R`
   (free end `R.last`), the arm at `u = L.last` is `L.reverse` (free end `L.head`). Each neighbour
   `u` of `x` whose edge `xu` lies in a path has exactly one arm; write `f(u)` for its free end.
   Vertices of `B` have no arm. Every neighbour `v` of `x` is an end of some path, so either some
   path avoiding `x` ends at `v` (`v` *live*) or `v = f(u)` for some `u`.
   Forest: `u → f(u)` has out-degree ≤ 1; the vertices whose `f`-iterates reach `b ∈ B` form a
   finite in-tree rooted at `b` (no cycles, since `b` has no out-edge); trees of different roots
   are disjoint. From each root `b` descend (`c₀ = b`, `f(c_{i+1}) = c_i`) until a live vertex
   `c_m` (exists: a non-live tree vertex has a child). Choose for each root such a chain and a path
   `Q_b` avoiding `x` that ends at `c_m`.
   Rebuild: reverse every arm attached at a non-root chain vertex (`L ↦ L.reverse` or
   `R ↦ R.reverse`; the path keeps its vertex set), append `x` to `Q_b` at `c_m` (a `Q` chosen at
   both ends becomes the cycle `Q ++ [x]`). Along a chain the `x`-edges telescope:
   `−xc₁+xc₀, −xc₂+xc₁, …, −xc_m+xc_{m−1}, +xc_m` = `+xb`. So the new family decomposes
   `E ∪ xB`, with the same size.
4. Main induction on `μ(E) = 2|E| + [E ≠ ∅ and every vertex of V(E) has odd degree]`, bound
   `2·size ≤ |V(E)|`:
   * some vertex `x` has an even-degree neighbour: `B` = even neighbours of `x`, `E' = E − xB`;
     in `E'` every neighbour of `x` has odd degree, so (1) + AL give `f(E) ≤ f(E')`; `|E'| < |E|`
     and `V(E') ⊆ V(E)`;
   * otherwise every vertex of `V(E)` has odd degree (so `|V(E)|` is even): if an edge `ab` has
     `deg a = deg b = 1` remove it (`V` shrinks by 2); else take `y` with `deg y ≥ 3`, `x ~ y`, a
     fresh vertex `ℓ`, `E_H = E − xy + xℓ` (`μ` drops: `y` has even degree ≥ 2 in `E_H`); IH gives
     `2 f(E_H) ≤ |V(E)| + 1`, hence `≤ |V(E)|`; AL (centre `y`, `B = {x}`) gives a decomposition
     of `E + xℓ` of the same size, and (2) removes `ℓ`.
   Fresh vertices: the induction runs on `V ⊕ ℕ`; the result is pulled back to `V`.
