# Errata to the candidate proof, manuscript v6.1

**Status.** The manuscript `proofs/manuscript/s1.tex` … `s7.tex` (v6.1, assembled by `ms.tex`) is a *candidate proof* of the Erdős–Gallai cycle decomposition conjecture. Only AI systems have reviewed it. No human has reviewed it. A Lean 4 proof of the formal-conjectures statement `Erdos184.erdos_184` (in `formal/`) passes local checks, CI, and the acceptance (release) run on GitHub (run 36767721300, 2026-09-30). This file lists 31 confirmed errata: 21 are still open in the v6.1 text and 10 are already corrected there. Every item is class T0 or T1. No item is T2/T3, so **these errata do not affect any stated theorem.** Two open items concern statements that are literally false in a degenerate case that no application reaches:

- the quoted B–M Lemma 15 fails at k = 0, but the manuscript does not use it;
- Lemma 14^τ(c) fails at n_0 = 1, τ = 0, but every application has τ ≥ 128.

Neither affects any result as it is used.

**Classes.**

- **T0**: formalization detail; the manuscript is fine, or the change is purely editorial.
- **T1**: the statement is true (in every case in which it is used), but the manuscript's proof or wording has a gap, typo or wrong constant.
- **T2/T3**: false statement. No such item is known.

Line numbers refer to the current v6.1 files. Evidence paths are relative to the repository root. `STATE.md` is the root project log. `TRIAGE.md` is `formal/work/p2/TRIAGE.md`. `PATCHES.md` and `FIXES.md` are in `proofs/manuscript/v61/`.
